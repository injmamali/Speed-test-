NEON//SPEED — SETUP GUIDE

FILES
- index.html : Main website structure
- style.css  : Electric-green robotic design and responsive layout
- script.js  : Speed test logic, animations, network info and copy report

HOW TO RUN
1. Keep all three files in the same folder.
2. Open index.html in a modern browser, or upload all files to GitHub Pages / Netlify / another static host.
3. Press INITIATE SPEED TEST and allow the browser to connect to Cloudflare's public speed test endpoint.

IMPORTANT
- This version measures download, upload and latency using Cloudflare's public endpoint at speed.cloudflare.com.
- An internet connection is required. Browser extensions, firewalls, VPNs, ISP restrictions or CORS/network policies may block the test endpoint.
- Results are estimates and can vary with Wi-Fi signal, device load, browser, ISP routing and network congestion.
- The browser's Network Information API is optional; some browsers do not expose those details.
- No API key, database, server installation or build step is required.
